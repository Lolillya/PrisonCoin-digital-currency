# PrisonCoin

**PrisonCoin: A Secure and Traceable Digital Currency System for Inmate Transactions in Controlled Environments**

---

## 🧩 Overview

**PrisonCoin** is a permissioned blockchain-based digital currency system tailored for use within correctional facilities. It enables a secure, accountable, and transparent financial environment for inmates, reducing risks associated with contraband trade and manual accounting.

---

## 🎯 Features

- 🛡️ **Permissioned Blockchain Economy**  
  Enables a closed-loop digital currency that can only be used within approved institutional settings.

- 📱 **Mobile User Interface**  
  Inmates can make purchases via a secure mobile application that mirrors a digital wallet.

- 🔐 **Biometric Authentication**  
  Fingerprint verification is used to authorize transactions and ensure identity validation.

- 📄 **On-Chain Transparency**  
  All transactions are recorded immutably on the blockchain to prevent tampering and enable auditability.

- 🧾 **Privacy & Access Control**  
  Ensures only authorized participants can access wallet and transaction information.

---

## 🔄 System Workflow

1. **Inmate Registration**  
   Inmate is enrolled into the system and assigned a unique wallet address.

2. **Currency Exchange**  
   External currency is converted to internal digital tokens and added to the inmate's wallet.

3. **Purchasing Process**  
   Inmate selects items to purchase; an operator verifies identity using fingerprint scan.

4. **Transaction Execution**  
   Tokens are deducted from the inmate’s balance and logged on-chain.
